工业标准品多平台询价与供应商比价系统 - 首次使用
====================================================

支持平台：1688、淘宝/天猫、京东、米思米中国。

一、接收方电脑要求

1. Windows 10/11（64 位）
2. Python 3.11 或更高版本，并在安装时勾选“Add Python to PATH”
3. Node.js 20 或更高的 LTS 版本
4. Google Chrome
5. 首次安装依赖时需要联网

官方下载地址：
Python: https://www.python.org/downloads/windows/
Node.js: https://nodejs.org/
Chrome: https://www.google.com/chrome/

二、安装和启动

1. 将 ZIP 完整解压到一个普通目录，不要在压缩包内直接运行。
2. 第一次使用：双击 install.bat，等待显示 Installation completed。
3. 以后使用：双击 start.bat，系统会启动并自动打开网页。
4. 如 8000 端口被占用，系统会自动选择 8001 等可用端口。

三、登录自己的平台账号

进入页面后，分别点击平台登录按钮，在弹出的浏览器窗口中完成登录。
登录状态只保存在本机的 cookies、browser_profiles，以及用户目录下的
.1688 文件夹中；接收方不会获得发送方的登录状态。

淘宝/天猫：完成登录后按登录窗口提示关闭窗口。
京东：使用独立 Chrome Profile 登录；日常搜索在后台执行。
1688：按弹出窗口提示完成登录。
米思米：需要价格或会员信息时登录自己的账号。

四、安全提示

完成登录后，不要把正在使用的整个目录再次发给别人。
如需再次分发，请使用原始的干净 ZIP；不要复制 cookies、
browser_profiles、data 数据库或用户目录下的 .1688 文件夹。

本工具仅用于正常采购询价。平台验证码、滑块和风控提示需要人工处理。
